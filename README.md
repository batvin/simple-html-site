# simple-html-site

یک سایت ساده HTML که روی **GitHub Pages** هاست شده.

## آدرس سایت
بعد از فعال کردن Pages:
**https://batvin.github.io/simple-html-site/**

## چطور Pages رو فعال کنی؟
1. برو به ریپازیتوری: https://github.com/batvin/simple-html-site
2. روی **Settings** کلیک کن
3. از منوی سمت چپ **Pages** رو انتخاب کن
4. در بخش **Build and deployment**:
   - Source رو بگذار روی **Deploy from a branch**
   - Branch رو بگذار روی **main** و فولدر **/ (root)**
5. Save کن

بعد از ۱-۲ دقیقه سایت بالا میاد.

## ویرایش سایت
فایل `index.html` رو ویرایش کن و تغییرات رو commit کن تا سایت آپدیت بشه.
